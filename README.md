# HousingMind

An AI-powered question-answering system for U.S. affordable housing policy.

HousingMind combines 2,500+ HUD policy documents with RAG (Retrieval-Augmented Generation) 
to provide accurate, source-cited answers about:

- **Housing Choice Voucher (Section 8)** program administration
- **Public Housing** regulations and operations  
- **LIHTC** (Low-Income Housing Tax Credit) compliance
- **RAD** (Rental Assistance Demonstration) conversions
- **HUD income limits**, Fair Market Rents, and subsidy calculations
- **HQS/NSPIRE** inspection standards

## Features

- Semantic search across PIH notices, handbooks, and 24 CFR regulations
- Automatic citation of regulatory sources (e.g., "24 CFR 982.201", "PIH 2023-15")
- REST API for integration with other applications
- Interactive CLI for quick policy lookups

Built for housing authorities, compliance officers, policy researchers, and housing advocates.
